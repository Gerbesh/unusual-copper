# Работа над проектом

Начните с [маршрута](docs/ROADMAP.md) и issue текущего milestone. Репозиторий пока содержит планирование; инструкция сборки будет добавлена с Forge MDK в UC-01.

- Одна законченная задача/исправление в ветке, PR в `main` со ссылкой на issue.
- В PR описать результат, применимые проверки и ограничения. Изменение баланса/контрактов/зависимостей пояснить и обновить документы.
- Проверки игрового кода после M0: сборка, относящиеся к задаче unit/GameTests, клиент и dedicated server при изменении путей загрузки/рендера/регистрации.
- Модели: `.bbmodel`, PNG, экспорт, игровые скриншоты и авторство; требования в [MODELING](docs/MODELING.md).
- Не считать обновление README достаточным основанием закрыть игровую задачу; критерии находятся в issue и ROADMAP.
- Не добавлять токены, личные пути, игровые миры, сторонние моды/jar и чужие лицензированные ресурсы без согласованного основания.

До приёма внешних вкладов закрыть D07: выбрать и объявить лицензии кода и ассетов.
