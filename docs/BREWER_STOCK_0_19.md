# Стабильные запасы автоклава — 0.19.0-alpha.1

16 октября 2026 года. Совместимый SSN Progressive: 1.2.4 и 1.3.0.

Экран раньше заменял запас ингредиентов очередной ограниченной страницей обхода SSN, а запас зелий мог показывать незавершённую сумму. Поэтому числа уменьшались и увеличивались без соответствующих перемещений предметов.

Теперь экран запрашивает полные счётчики: один ключ/тип ингредиента за тик меню. Для реагентов суммируются подходящие NBT-варианты предмета, включая переименованные; для зелий сохраняется точное сравнение NBT. Фильтры SSN проверяются для каждого варианта. Ключи не конкурируют за прежний кэш из 16 строк: лимит увеличен до 32.

`StableCount` заменяет число только после полного подсчёта. При следующем обходе остаётся предыдущий полный результат с `≈`; `…` означает, что полного результата ещё не было. Полностью подтверждённый ноль заменяет старый запас. Локальные слоты машины учитываются отдельно; смена привязки очищает наблюдения. Эти числа используются для интерфейса, а физическая работа машины сохраняет собственные проверки.

Добавлены JUnit-сценарии сохранения предыдущего полного результата и подтверждённого нуля. Добавлен GameTest для полного подсчёта обычных/переименованных ингредиентов и фильтра на большом инвентаре; он только скомпилирован. Проверка в игре остаётся пользователю. Итог сборки и SHA-256 — в `verification/brewer-stock-2026-10-16.json`.
