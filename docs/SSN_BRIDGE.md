# SSN Bridge — проверка 15 октября 2026

## Совместимость

Целевая среда: Minecraft 1.20.1, Forge 47.4.20, JDK 17; сборка разработки — Forge 47.4.10.
Серверный адаптер рассчитан на Simple Storage Network 1.13.2 и, при наличии, SSN Progressive 1.2.4.
Права проверены с Open Parties and Claims 0.30.1. Другие версии и произвольные storage API не заявлены.
Точный испытанный JAR SSN: SHA-256 `1DB6F5595E5EDC255DB6800DE9E0E1AA8E01E10D79D1784D549D70EB2CF53012`.
Адаптер требует обнаруженные API и хук ревизии; совпадение номера версии другой сборки само по себе не доказывает совместимость.

Блок `ssn_bridge` соединяет машины Unusual Copper с физическими хранилищами сети SSN.
Поворачивается селектором владельца; Shift + ПКМ переключает redstone-режим.
Без SSN мост остаётся недоступным, но обычные трубы и сундуки работают независимо.
Нет FE-порта, chunk loading или принудительной загрузки выгруженных хранилищ.

## Прогоны

- `gradlew.bat --no-daemon -PssnTests build`: успешно, Java 17, JUnit без ошибок.
- `gradlew.bat --no-daemon runGameTestServer`: **117/117** после добавления теста смены адаптера.
- Нативный SSN 1.13.2 без Progressive: все обязательные маркеры `tools/run_ssn_probe.py` пройдены.
- SSN + Progressive 1.2.4 + OpenPAC 0.30.1: все обязательные маркеры пройдены.

Проверены 19 хранилищ, NBT, приоритет ссылок, 512-слотовый инвентарь и дальняя вставка,
фильтр/направления, двойной сундук без двойного учёта, отказ доступа после смены владельца привата.
Два автоклава через разные мосты произвели 16 реальных зелий за 80 000 CuE,
потратив шесть партий реагентов. Progressive рекурсивно создал два железных меча,
а параллельная плавильня вернула три слитка железа за 720 CuE.
Штатный перезапуск восстановил оплаченный этап, владельца и физические предметы.
Итоговый обычный JAR `0.10.0-alpha.1` повторно прошёл совместный серверный профиль;
хеш артефакта и выдержки журнала: [свидетельства 0.10](verification/ssn-jei-2026-10-15.txt).

## Ограничения до 1.0

Нативный адаптер считает только доступные загруженные хранилища, а неизвестные точные остатки
помечает `Count.complete() == false`. Отбор ограничен восемью портами за операцию;
большие инвентари индексируются порциями по 256 слотов. Это не замена профилированию MSPT.
Нужны отдельные проверки crash-атомарности между чанками (D11), модовых storage handlers,
вариантов дублей и фильтров SSN-ссылок, остальных категорий JEI, полного целевого модпака и клиентского поведения.
