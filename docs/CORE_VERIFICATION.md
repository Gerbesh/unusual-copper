# Проверка ядра 0.1.0-alpha.1

Дата: 2026-10-14. Платформа локальной проверки: Windows x64, Java 17.0.19, Forge 47.4.10, Minecraft 1.20.1, official mappings, Gradle 8.8. Целевой модпак использует Forge 47.4.20; полная совместимость с ним ещё не подтверждена.

## Реализовано

Солнечный насытитель, линза на 16 384 входные единицы, эссенция, расщепитель на 50 000 CuE, энергопровод, ячейка I на 250 000 CuE и плавильня на 24 000 CuE. Собственная CuE capability, направленные порты, redstone, сохранения, серверные настройки, GUI, RU/EN, рецепты/loot/datagen и пять моделей Blockbench. FE capability не публикуется.

В dedicated-фикстуре готовая эссенция переносится тестовым кодом в расщепитель: предметные трубы ещё не реализованы. Чтобы сервер без игроков не остановил тики через 300 тиков, фикстура временно удерживает только свои чанки и снимает удержание перед остановкой. Этот код отсутствует в production JAR; мод не загружает чанки. Клиентская и серверная сцены используют только собственные каталоги `run/` и `run-server/`.

## Повторение

```powershell
.\gradlew.bat --no-daemon build runGameTestServer
.\gradlew.bat --no-daemon -PsmokeClient runClient
.\gradlew.bat --no-daemon -PsmokeServer runServer
.\gradlew.bat --no-daemon runData
```

Для клиентской сцены заранее нужен собственный мир `run/saves/cue-smoke` (обычный тестовый мир). Для server smoke подготовьте отдельный `run-server/server.properties`: loopback, свободный порт, плоский мир и действующие условия Minecraft. В локальной проверке использована копия уже существующего `eula=true` пользователя; его игровой сервер не запускался и не менялся. Автоматические сцены завершают процесс после снимков или успешной цепочки; обычные команды без флага не включают этот режим.

Не считайте один `BUILD SUCCESSFUL` доказательством server smoke: Minecraft может завершить аварийный сервер с кодом 0. Требуется строка **`CuE DEDICATED SMOKE PASS`** и отсутствие ошибок самого мода. Первый проход выявил остановку тиков пустого сервера; повторный проход с явной тестовой фикстурой прошёл.

## Осталось до 1.0

Предметное хранение/трубы, жезл и грани, области и политика прав, культиватор, пастырь, жнец, арборист, страж, автоклав, зачарователь, мост SSN/SSN Progressive, JEI и руководство. Далее — все T01–T36 на чистом Forge и целевом модпаке, actual chunk unload/reload, crash-сценарии, ownership/claims, производительность и окончательное искусство/звук/свечение. Без этих этапов ядро не является завершённым релизом 1.0.

Граф имеет ограничение размера компоненты и числа попыток передачи, но его перестроение пока синхронное; итоговый бюджет для больших сетей должен подтверждаться профилированием и доработкой планировщика. Серверные настройки пропускной способности выше 256 требуют отдельной доработки согласованного лимита capability. Поддержка tier II/III, сложных сторонних рецептов и неизвестных handlers пока не заявлена.
