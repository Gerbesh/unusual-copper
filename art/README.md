# Художественные исходники Unusual Copper

`blockbench/` содержит редактируемые Java Block/Item `.bbmodel` машин и четырёх видов труб. Текстуры металла и стекла встроены в проекты. Экспорт находится в `src/main/resources/assets/unusualcopper/`; исходники не ссылаются на личные пути Windows.

С версии `0.13.0-alpha.1`:

- `sprites/sources/` — девять исходных PNG, созданных встроенным **image_gen**, `sprites/prompts.json` — точные общая часть и предметные части запросов. `sprites/*.png` — игровые RGBA-спрайты 64×64, `sprites/preview.png` — обзор.
- `surfaces/sources/` — выбранные исходники меди, патины и тёмного металла из image_gen. Запросы записаны в `surfaces/prompts.json` и `surfaces/final-edits.json`. При подготовке игровых размеров сохраняется рисунок, используется nearest-neighbor.
- `textures/` — экспортированные материалы 32×32. Стекло содержит только блики; энергия больше не нарисована на стекле. Сетка солнечной панели и шкала манометра задаются кодом генератора.
- `previews/visual-*.png` — настоящие кадры тестового клиента: пустая/работающая/заряженная линия, низкий корпус, шесть направлений подключения, семейство машин и предметы.

Воспроизведение: `python tools/import_item_sprites.py`, затем `python tools/generate_assets.py` и `python tools/check_visual_assets.py`. Генератор сохраняет авторские спрайты; при отсутствии исходника завершает работу с ошибкой. Старые процедурные заглушки не восстанавливаются.

Редактируемые модели сохраняют объёмные кубоиды; при экспорте генератор отсекает скрытые и перекрывающиеся плоскости. Порты и движущиеся части рисуются клиентскими `CopperMachineRenderer`/`EnergyPipeRenderer`. Статичный Java JSON не содержит их анимаций. Правила и проверка описаны в [VISUALS.md](../docs/VISUALS.md).

Изображение `docs/references/visual-style.png` используется как референс палитры и материалов, а не как игровая текстура. Старые превью в этом каталоге показывают предыдущие прототипы.
