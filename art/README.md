# Исходники художественных материалов

В `blockbench/` сохранены пять редактируемых `.bbmodel`: солнечный насытитель, расщепитель, ячейка, плавильня и энергопровод. Встроены исходные 32×32 пиксельные текстуры; стекло имеет четыре анимированных кадра. Экспортированные JSON/PNG находятся в `src/main/resources/assets/unusualcopper/`.

Ассеты созданы детерминированным `tools/generate_assets.py`. Референс в `docs/references/visual-style.png` задаёт материалы и палитру; его изображение не используется как игровая текстура. `previews/copper_cell_blockbench.png` получен из веб-редактора Blockbench, `previews/core_chain_ingame.png` — из реального Minecraft.

Следующие машины и художественная полировка остаются в работе. Порядок и приёмка: [руководство по моделированию](../docs/MODELING.md).
