# Unusual Copper

Технологически-магический мод для **Minecraft Java 1.20.1 / Forge 47.x / Java 17**. Медь становится постоянным расходником: солнечное насыщение → эссенция → энергия CuE → машины автоматизации.

**Состояние: разработка.** Работают солнечный насытитель, расщепитель эссенции, сеть CuE, ячейки I–III, резонансная плавильня, предметные трубы, культиватор ауры, магнитный коллектор и Пастырь роста. Есть фильтры/NBT/теги, приоритеты и пороги запасов, сохраняемый груз, жезл областей/привязки хранилища, селектор граней, серверные настройки, RU/EN и исходники моделей Blockbench. Добавлены прототипы Жнеца с реальной смертью/добычей и Арбориста с размеченными деревьями, топором и пересадкой. Их права проверены с Open Parties and Claims 0.30.1; реализованы клиентские эффекты. Полная приёмка ферм и сильной магии, все категории JEI и релизная матрица ещё впереди; объём 1.0 сохранён в маршруте.

В M4 добавлены [Медный часовой](docs/COPPER_SENTINEL.md), [Эфирный автоклав](docs/AETHERIC_BREWER.md) и [Резонатор зачарований](docs/ENCHANTMENT_RESONATOR.md). Текущая версия — `0.13.0-alpha.1`: [визуальный проход](docs/VISUALS.md) заменяет предметные спрайты, исправляет стыки труб, добавляет видимый заряд/направленный поток CuE и рабочие механизмы машин. Сохранены [три класса проводов/ячеек](docs/ENERGY_TIERS.md), [приоритеты, разветвитель и монитор](docs/ENERGY_CONTROL.md). [SSN Bridge](docs/SSN_BRIDGE.md) проверен с SSN 1.13.2, Progressive 1.2.4 и OpenPAC 0.30.1; JEI показывает четыре рецепта солнечного насыщения из текущего мира. Полноценная beta ещё не готова.

## Первый полезный прототип

```text
64 медных слитка + солнечная линза + дневное небо
    → 128 эссенций → 64 000 CuE
    → энергопровод → ячейка I → резонансная плавильня
```

Плавильня проверяет пользу всей цепочки: типовой рецепт 200 тиков выполняется за 20 тиков, одна операция стоит 240 CuE, выход соответствует рецепту. До этого необходимо обеспечить сохранения, корректную передачу энергии и остановку при заполненном выходе.

## Инструменты

Разработка ядра проверена на Forge **47.4.10**, official mappings **1.20.1**, Java **17**, Gradle **8.8**, ForgeGradle **6.0.54**. Целевой пользовательский модпак использует Forge **47.4.20**; его полная проверка относится к релизной матрице.

```powershell
.\gradlew.bat --no-daemon build
.\gradlew.bat --no-daemon runGameTestServer
.\gradlew.bat --no-daemon runClient
.\gradlew.bat --no-daemon runData
```

JAR после сборки: `build/libs/unusualcopper-0.12.0-alpha.1.jar`. GameTests, автоматические сцены и production probe не включаются в обычный JAR. Для текущего этапа прошли 129 обязательных GameTests и 14 JUnit; результаты проверки обычного JAR записаны в [отчёте 0.12](docs/verification/energy-control-2026-10-15.txt). Зелёный отдельный тест не означает завершения полной матрицы 1.0.

Ассеты генерируются `python tools/generate_assets.py` (нужен Pillow). Тестовая структура — `python tools/generate_test_structure.py` (стандартная библиотека Python). Экспорты и `.bbmodel` сохранены в Git, поэтому Python для обычной сборки мода не требуется.

- Код: JDK 17, IntelliJ IDEA или другая IDE с Gradle, Forge MDK выбранной версии 47.x.
- Модели: [Blockbench](https://blockbench.net/) и исходники `.bbmodel`.
- Текстуры: встроенный редактор Blockbench; Aseprite/GIMP/Krita по предпочтению художника.
- Анимации: стандартные текстуры и `BlockEntityRenderer`; GeckoLib рассматривается отдельно после прототипа.
- Совместимость: обычные сундуки и Forge `IItemHandler`, опциональные SSN/SSN Progressive и JEI; испытанные версии и пределы указаны в документах интеграций.

Gradle wrapper и CI уже включены в репозиторий. Открытые критерии последующих этапов перечислены в маршруте и GitHub issues.
